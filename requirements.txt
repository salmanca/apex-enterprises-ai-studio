# QUICK LOCAL SETUP INSTRUCTIONS
# ------------------------------------------------------------------------------
# 1. Clone or extract the project folder onto your computer.
# 2. Open a terminal / command prompt inside the project folder.
# 3. Install all npm dependencies:
#      npm install
#
# 4. (Optional) Create local environment file:
#      cp .env.example .env
#
# 5. Launch development server:
#      npm run dev
#
# 6. Open your web browser:
#      http://localhost:3000
#
# 7. Production build & start:
#      npm run build
#      npm start
